## 3. ที่ยังไม่ได้ทดสอบ / ข้อจำกัด

- **ไม่ได้ทดสอบบน Safari/Firefox และอุปกรณ์จริง** — ทดสอบเฉพาะ Chromium ที่จำลองขนาดจอ
- **ไม่ได้ทดสอบการ deploy จริงบน Netlify** — ตรวจเฉพาะ `netlify.toml`/`_headers` และจำลอง header ในเครื่อง
- **ไม่ได้ตรวจว่า URL ภายนอก 42 แหล่งเปิดได้จริง** — เครือข่ายของสภาพแวดล้อมทดสอบปิดกั้นโดเมนภายนอก (ตรวจเฉพาะกติกาความลึก/เครื่องหมาย ?) ต้นฉบับระบุว่าตรวจเมื่อ 13 ต.ค. 2569
- ฟอนต์ IBM Plex Sans Thai / Bai Jamjuree / IBM Plex Mono โหลดจาก Google Fonts ได้ภายใต้ CSP (ตรวจด้วย `document.fonts`) แต่ถ้าเปิดออฟไลน์จะใช้ฟอนต์ระบบแทน
- ไม่ได้ทดสอบกับ Copilot / Agent Builder จริง (ข้อมูลเรื่องเมนูและสิทธิ์บัญชีติดป้าย "ตรวจกับบัญชีจริงก่อนสอน" ตามต้นฉบับ)
