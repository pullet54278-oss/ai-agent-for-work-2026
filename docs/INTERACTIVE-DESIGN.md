## 0. หลักการ

1. **เอนจินกลาง + ชุดธีม (theme pack)**: ทุกลูกเล่นเขียนครั้งเดียว ใช้ได้ทั้งแอป Copilot (ธีม Fluent + Copilot ปัจจุบัน) และแอปคอร์สถัดไปตาม `docs/MASTER-BLUEPRINT.md` (เช่น ChatGPT ธีมดำ-ขาว-เขียว `#10A37F`) โดยเปลี่ยนแค่ token และข้อมูลฉาก
2. **ไม่ฝ่ากติกาเดิม**: ไฟล์เดียว + lazy data, CSP แบบ hash (ไม่มี `eval`/`new Function`/inline handler), ทำงานออฟไลน์ (PWA), ไม่เลียนแบบโลโก้, คำว่า Copilot สี `--ink`, ห้ามชื่อบริษัท/ตำแหน่ง, ชื่อเมนูและปุ่มของ Copilot ติดป้าย "ตรวจกับบัญชีจริงก่อนสอน" จนกว่าจะได้ภาพหน้าจอ
3. **เนื้อหามาก่อนลูกเล่น**: ทุกเดโมมีข้อความถอดความ (transcript) ให้อ่านได้โดยไม่ต้องดูแอนิเมชัน · ใช้คีย์บอร์ดได้ครบ · `prefers-reduced-motion` ลดแอนิเมชันเอง
4. **หน้าจอจำลองวาดด้วย HTML/CSS ไม่ใช้ภาพหน้าจอจริง**: คมทุกขนาด เปลี่ยนธีมได้ แปลภาษาได้ ไม่ติดลิขสิทธิ์ภาพ UI · หน้าตา "ใกล้เคียง" ไม่ใช่สำเนา และมีป้าย "หน้าจอจำลองเพื่อการเรียน"
5. **งบประสิทธิภาพ**: JS ส่วนลูกเล่นรวม ≤ 70 KB (ไม่บีบอัด) · ข้อมูลฉากโหลดเมื่อใช้ (`sims-data.js`) · แอนิเมชันใช้เฉพาะ `transform`/`opacity` · หยุดเมื่อแท็บถูกซ่อนหรือออกนอกจอ · 60 fps บนมือถือระดับกลาง

## 2. หน้าจอจำลองที่เล่นเองได้ (Sim Player) — จุดเด่นหลัก

### 2.1 ข้อมูลฉาก (`content/sims/agent-builder-create.mjs`)

```js
export default {
  id: 'agent-builder-create',
  title: 'สร้าง Agent ใน Agent Builder',
  app: 'copilot',                // theme pack ของหน้าจอจำลอง
  stage: { w: 1280, h: 800 },    // ขนาดตรรกะ ย่อ/ขยายด้วย CSS scale
  verify: true,                  // แสดงป้าย "ตรวจกับบัญชีจริงก่อนสอน"
  screens: {
    home:   [{ ui: 'sidebar', items: ['Chat', 'Agents & Skills'] }, { ui: 'chat', messages: [] }],
    create: [{ ui: 'panel', title: 'New agent', tabs: ['Describe', 'Configure'] }, { ui: 'field', id: 'name', label: 'Name' }]
  },
  steps: [
    { screen: 'home',   target: 'sidebar:Agents & Skills', act: 'click', tip: 'เปิดเมนู Agents & Skills ด้านซ้าย' },
    { screen: 'home',   target: 'button:New agent',        act: 'click', tip: 'กด New agent เพื่อเริ่มสร้าง' },
    { screen: 'create', target: 'tab:Configure',           act: 'click', tip: 'เลือกแท็บ Configure เพื่อกรอกเอง' },
    { screen: 'create', target: 'field:name',              act: 'type', text: 'ผู้ช่วยขั้นตอนงาน', tip: 'ตั้งชื่อไม่เกิน 30 ตัวอักษร' },
    { screen: 'create', target: 'dialog:consent',          act: 'choose', options: ['allow-once', 'always', 'deny'], tip: 'เลือกการอนุญาต' }
  ]
};
```

- `target` อ้างชิ้นส่วนด้วย `ชนิด:ชื่อ` (ไม่ใช้ CSS selector ในข้อมูล) → build ตรวจว่าทุก target มีอยู่จริงในหน้าจอของขั้นนั้น
- ชิ้นส่วน UI จำลอง (ui primitives): `window`, `sidebar`, `chat`, `bubble`, `input`, `button`, `tab`, `panel`, `field`, `toggle`, `filechip`, `toolcall`, `dialog:consent`, `toast` · วาดเป็น DOM จริง (มี role/label) จึงกดด้วยคีย์บอร์ดและ screen reader อ่านได้

### 2.2 สถานะของผู้เล่น

```
idle ──เล่นอัตโนมัติ──▶ auto(step i) ──จบขั้น──▶ auto(i+1) … ──▶ done (สรุป + ปุ่มเล่นซ้ำ)
  └──ลองกดเอง──▶ guided(step i) ──กดถูก──▶ guided(i+1)
                      └──กดผิด──▶ เขย่า + คำใบ้ (ผิด 2 ครั้ง → ลูกศรชี้ + ข้อความชัดขึ้น)
```

- **เคอร์เซอร์**: Web Animations API เคลื่อนตามเส้นโค้ง (bezier) จากตำแหน่งเดิมไปกลางเป้าหมาย 500–900 ms ตามระยะ → กด (ย่อ-ขยาย) → ผลลัพธ์บนหน้าจอ
- **วงแสงกะพริบ**: `box-shadow` + `@keyframes` บนกรอบเป้าหมาย (โหมดลดการเคลื่อนไหว = กรอบนิ่งหนา)
- **กล่องคำอธิบาย**: วางข้างเป้าหมาย คำนวณตำแหน่ง ขวา → ซ้าย → ล่าง → บน (กลับด้านเมื่อล้นขอบ) · บนจอเล็กย้ายไปแถบล่างของหน้าจอจำลอง
- **แถบควบคุมด้านล่าง**: เล่น/หยุด · ย้อน/ถัดไป · ความเร็ว 0.75× / 1× / 1.5× · สลับ "ดูอัตโนมัติ / ลองกดเอง" · แถบความคืบหน้าแบบมีจุดขั้นตอน (กดจุดเพื่อข้ามได้) · "ขั้นที่ 3/8"
- **ย่อพอดีจอ**: `ResizeObserver` คำนวณ `scale = min(1, กว้างกล่อง / stage.w)` แล้ว `transform: scale()` บนเวที · พิกัดเคอร์เซอร์คิดในหน่วยตรรกะ จึงไม่เพี้ยน
- **มือถือ**: ลากซ้าย/ขวา (Pointer Events, ระยะ > 48 px และแนวนอนชัดเจน) เพื่อเปลี่ยนขั้น · แตะเป้าหมายในโหมดลองกดเอง · ปุ่มใหญ่ ≥ 44 px
- **คีย์บอร์ด**: Space = เล่น/หยุด · ← → = ขั้นก่อน/ถัดไป · Enter บนเป้าหมาย = กด · ประกาศขั้นใหม่ผ่าน `aria-live`
- **ข้อความถอดความ**: รายการขั้นตอนแบบข้อความใต้หน้าจอจำลอง (พับได้) = เนื้อหาเดียวกับ tip
- **โหมดลดการเคลื่อนไหว**: ไม่เล่นอัตโนมัติเอง เคอร์เซอร์กระโดดไปตำแหน่งทันที ไม่มีวงกะพริบ

## 3. บทเรียนแรกเป็นเส้นทางเดียว (Journey)

- หน้าใหม่ `#/journey` (ลิงก์จากปุ่มหลักบนหน้าแรก และหน้า 1 ของบทที่ 1)
- 7 สถานี: **เป้าหมาย → สิทธิ์ → ข้อมูล → เครื่องมือ → ขออนุญาต → ผลงาน → ส่งมอบ** (ข้อความใน `content/journey.mjs`)
- เส้นเชื่อม: SVG `path` แนวตั้ง ใช้ `stroke-dashoffset` ตามสัดส่วนการเลื่อนหน้า
  - ใช้ CSS scroll-driven animation (`animation-timeline: view()`) ถ้าเบราว์เซอร์รองรับ
  - ถ้าไม่รองรับ ใช้ scroll listener + `requestAnimationFrame`
  - สีเส้นจาก token `--journey` (Copilot = `--accent`, ChatGPT = `#10A37F`)
- สถานีเปิดเดโม (Sim Player ขนาดเล็ก) เมื่อเลื่อนถึง (IntersectionObserver) หรือกดปุ่ม "ดูเดโม"
- **จุดขออนุญาต (สถานีที่ 5)**: ผู้เล่นหยุดรอ ไม่ไปต่อเอง ผู้เรียนเลือก 1 ใน 3
  - **อนุญาตครั้งนี้**: งานเดินต่อ ครั้งหน้าจะถามใหม่ (ปลอดภัย แนะนำ)
  - **อนุญาตเสมอ**: งานเดินต่อและไม่ถามอีก (สะดวก แต่ความเสี่ยงสูงขึ้น) แสดงคำเตือนสีส้ม
  - **ไม่อนุญาต**: งานหยุด แล้วสถานีที่ 6 แสดง "ทางเลือกเมื่อไม่ได้สิทธิ์" (แนบไฟล์เองในแชท)
  - ผลที่เลือกส่งต่อไปสถานีถัดไป และจำไว้ใน `cpa26-journey`
  - ชื่อปุ่มในแอป Copilot ใช้ภาษากลางตามด้านบน และติดป้ายตรวจกับบัญชีจริง ส่วนแอป ChatGPT ใช้ Allow once / Always allow / Deny
- จบเส้นทาง → พลุ + เหรียญ "ผู้เริ่มต้นเส้นทาง Agent"

## 4. Prompt Lab แบบเครื่องผลิต (Forge)

- หน้า `#/forge` (และแทนที่ Prompt Builder หน้า 9 ด้วยลิงก์ โดยไม่แตะเนื้อหาต้นฉบับ)
- **ซ้าย**: ช่องกรอก เป้าหมาย / ข้อมูล / สิทธิ์ (อ่านอย่างเดียว · แก้ไขได้ · ส่งออกได้ + ระดับการอนุญาต) / ผลลัพธ์ · ใช้ตัวอย่างสำเร็จรูปได้
- **กลาง**: Prompt ประกอบตัวเองแบบพิมพ์ทีละตัว
  - `requestAnimationFrame` พิมพ์ประมาณ 40 ตัวอักษรต่อวินาที ตามคำ (ใช้ `Intl.Segmenter('th')` ไม่ตัดกลางคำไทย)
  - แก้ฟอร์มระหว่างพิมพ์ = เริ่มพิมพ์ส่วนที่เปลี่ยนใหม่ · มีปุ่มข้ามแอนิเมชัน
  - โหมดลดการเคลื่อนไหวแสดงทันที
- **ขวา**: ภาพจำลอง Agent ทำงาน
  - ไอคอนเครื่องมือเด้งตามลำดับ (ค้นข้อมูล → อ่านไฟล์ → วิเคราะห์ → สร้างไฟล์) ใช้ Fluent icons ไม่ใช้โลโก้ผลิตภัณฑ์
  - ได้การ์ดไฟล์ผลงาน แล้วขึ้น "เสร็จแล้ว" (ธีม ChatGPT ขึ้น "Turn complete")
- **มาตรวัดความพร้อมของคำสั่ง** 0–100: ฟังก์ชันบริสุทธิ์ `scorePrompt(form)` ทดสอบแยกได้
  - +25 เป้าหมายชัด (มีคำกริยา + สิ่งที่ส่งมอบ)
  - +20 ระบุแหล่งข้อมูล
  - +20 รูปแบบผลลัพธ์ชัด
  - +15 มีบรรทัดตรวจสอบ/ห้ามแต่ง
  - +20 สิทธิ์ต่ำที่สุดที่พอใช้
  - สี: < 50 แดง · 50–79 เหลือง · ≥ 80 เขียว
  - **สิทธิ์สูงเกินจำเป็น** (อนุญาตเสมอ หรือ "ส่งออก/ส่งอีเมล" ทั้งที่งานแค่สรุป) → มาตรวัดขึ้นสีส้ม พร้อมคำเตือนและปุ่ม "ลดสิทธิ์"
- ใช้ตัวช่วยเดิมของ `promptlab.js` (ตัดคำไทย ตรวจหัวข้อ) และปุ่มคัดลอกเดิม

## 5. คลังเครื่องมือ (~40 หัวข้อ)

- ข้อมูล `content/library.mjs`: `{ slug, title, cat, icon, short, body (Markdown), links: [p:…, d:…, s:…] }` · 40 หัวข้อคัดจากเนื้อหาที่มีอยู่
  - หมวดตัวอย่าง: Copilot Chat · Agent · Excel · Word/PowerPoint · Outlook/Teams · เบราว์เซอร์ · ความปลอดภัย · เทคนิค Prompt
  - **รายการ 40 หัวข้อให้เจ้าของงานยืนยันก่อนเขียน**
- สีตามหมวดใช้ token กลุ่มเดิม (`--g-*`) · ช่องค้นหา (ใช้ดัชนีเดียวกับ Ctrl+K) · ชิปกรองหมวด · จำตัวกรองไว้
- **การ์ดขยายเต็มจอ**:
  - เมื่อแตะ เรียก `document.startViewTransition()` โดยตั้ง `view-transition-name` เดียวกันให้การ์ดและหัวหน้ารายละเอียด แล้วเปลี่ยน route `#/lib/{slug}`
  - ปุ่มย้อนกลับเล่นย้อนทาง
  - เบราว์เซอร์ที่ไม่รองรับหรือโหมดลดการเคลื่อนไหว เปลี่ยนหน้าทันที
- Router: เพิ่ม `#/lib` และ `#/lib/{slug}` แบบเดียวกับ `#/s/{slug}` (หัวข้อคลังไม่นับในความคืบหน้าหลัก)

## 6. ภาพรวมและความรู้สึก

| ลูกเล่น | วิธีทำ | เมื่อลดการเคลื่อนไหว |
|---|---|---|
| ธีม | theme pack = ชุด CSS custom properties บน `:root[data-course]` · Copilot ใช้ token เดิม · ChatGPT: `--accent:#10A37F` ดำ/ขาว | — |
| พื้นหลังเรืองแสง | 2–3 วง `radial-gradient` บนชั้น `position:fixed` เคลื่อนช้า 30–60 วินาทีด้วย `@property` + keyframes · หยุดเมื่อแท็บซ่อน · ทึบลงในโหมดมืด | ภาพนิ่ง |
| ระลอกปุ่ม | `pointerdown` สร้าง span วงกลมใน `.btn` แล้วลบเมื่อจบ (delegated listener เดียว) | ไม่มีระลอก |
| การ์ดเอียง | `pointermove` เฉพาะ `(hover:hover) and (pointer:fine)` เอียง ≤ 4° ด้วย `transform: perspective() rotateX/Y` · rAF throttle | ไม่เอียง |
| ตัวเลขนับขึ้น | IntersectionObserver เริ่มนับ 800 ms easeOut · ใช้ `Intl.NumberFormat('th-TH')` · ค่าจริงอยู่ใน DOM ตั้งแต่แรก (อ่านได้เสมอ) | แสดงค่าทันที |
| พลุจบบท | `<canvas>` 1.5 วินาที ประมาณ 120 ชิ้น สีจาก theme · ยิงเมื่อทำเครื่องหมายครบบท / จบเส้นทาง / ได้เหรียญ | แสดงเหรียญอย่างเดียว |
| เสียงเอฟเฟกต์ | Web Audio สังเคราะห์ (คลิก, สำเร็จ, เหรียญ, ผิด) ระดับเสียงต่ำ · **สร้าง AudioContext หลังผู้ใช้เปิดเสียงเท่านั้น** · ปุ่มเปิด/ปิดที่แถบบน + จำค่า `cpa26-sound` | ใช้ได้ (ไม่เกี่ยวกับการเคลื่อนไหว) |
| คลื่นเสียง + คำบรรยาย | `wave.js`: canvas แท่งคลื่นขยับตามจังหวะจำลอง + คำบรรยายซิงก์ตาม timestamps ในข้อมูล | คลื่นนิ่ง คำบรรยายยังแสดง |
| มือถือ | ใช้แถบเมนูล่างเดิม (เพิ่มปุ่มคลังเครื่องมือ) · ลากเปลี่ยนขั้นในหน้าจอจำลอง · หน้าจอจำลองย่อพอดีจอ | — |

- ค่าเริ่มต้นเสียง: **เสนอให้ปิดไว้** (ห้องอบรม/ที่ทำงาน) ให้เจ้าของงานยืนยัน
- **บทเรียน Voice**: แอป Copilot ไม่มีบทนี้ จึงเตรียม `wave.js` ไว้ใช้ในคอร์ส ChatGPT

## 8. การทดสอบ (เพิ่มใน `tests/e2e.mjs`)

- **Sim**
  - โหมดอัตโนมัติจบทุกขั้น
  - โหมดลองกดเอง: กดถูกไปต่อ กดผิดมีคำใบ้ ผิด 2 ครั้งมีลูกศร
  - คีย์บอร์ด, ลากบนจอสัมผัส (touch emulation), ย่อพอดีจอที่ 360 px
  - ข้อความถอดความตรงกับ tip
  - build ล้มเมื่อ target ไม่มีอยู่
- **Journey**
  - เส้นยาวขึ้นตามการเลื่อน
  - จุดขออนุญาตหยุดรอ ทั้ง 3 ปุ่มให้ผลและคำอธิบายถูก ผลส่งต่อสถานี 6
  - จำค่าได้
- **Forge**
  - `scorePrompt` กรณีทดสอบ ≥ 10 กรณี
  - สิทธิ์สูง → สีส้ม + คำเตือน
  - ข้ามการพิมพ์ได้ และ Prompt สุดท้ายตรงกับฟอร์ม
- **Library**: ค้นหา/กรอง, View Transition (Chromium) และทางสำรองเมื่อไม่รองรับ, ปุ่มย้อนกลับ
- **Feel**
  - reduced-motion ปิดแอนิเมชันทุกตัว (ตรวจ `getAnimations()` ว่าว่าง)
  - เสียงปิดเป็นค่าเริ่มต้น และไม่มี AudioContext จนกว่าจะเปิด
  - พลุยิงเมื่อจบบท
- **Progress**: เหรียญปลดล็อกและคงอยู่หลัง reload, แบบทดสอบท้ายบท, เช็กลิสต์จำค่า
- **ภาพรวม**
  - ไม่มี console error ภายใต้ CSP
  - ไม่มีการเลื่อนแนวนอน (1440/1024/820/390/360)
  - axe 0 serious
  - FPS ระหว่างเล่นฉาก ≥ 50 บน CPU throttle 4× (Chromium)
- **ส่งมอบ**: `npm run audit` ขาด 0 · e2e ผ่านทั้งหมด · ภาพหน้าจอ Desktop/Mobile × Light/Dark
