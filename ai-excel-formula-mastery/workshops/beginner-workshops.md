## คู่มือ Workshop (ส่วนขยาย)

### Workshop 1: คำนวณยอดขายและค่าเฉลี่ยรายวัน

- เวลา: 30 นาที

- ข้อมูล: ชีต Sales_Data: A Order_ID, B Order_Date (วันที่จริง), C Product_ID, D Channel, E Quantity, F Unit_Price — ใช้ 3 แถวตามต้นฉบับ (O001–O003) แล้วเพิ่มแถวทดสอบเอง 2 แถว (Quantity ว่าง 1 แถว, Unit_Price เป็นข้อความ 1 แถว) · สร้างตารางสรุปในชีต Calculations: J = Date (2026-10-01 ถึง 2026-10-03), K = Daily_Sales

- เป้าหมาย: คำนวณยอดขายต่อออเดอร์ ยอดรวมรายวัน ยอดรวมทั้งหมด และค่าเฉลี่ยยอดขายต่อวัน (เฉพาะวันที่มีการขาย) จาก Sales_Data พร้อมตรวจความถูกต้อง

**ขั้นตอน**

1. ตรวจชนิดข้อมูลก่อน: =COUNT(E2:F100) เทียบ =COUNTA(E2:F100) และ =ISNUMBER(B2) ต้อง TRUE
2. เพิ่มคอลัมน์ G = Amount ใน Sales_Data: =IF(OR(E2="",F2=""),"",E2*F2) แล้วลากลง
3. ในชีต Calculations ใส่วันที่ใน J2:J4 แล้วคำนวณยอดรายวัน K2: =SUMIF(Sales_Data!$B$2:$B$100,J2,Sales_Data!$G$2:$G$100)
4. ยอดรวมทั้งหมด: =SUM(Sales_Data!G2:G100)
5. ค่าเฉลี่ยรายวัน (วันที่มีการขาย): =ROUND(AVERAGE(K2:K4),2) และแบบปลอดภัย =IF(COUNT(K2:K4)=0,"",ROUND(AVERAGE(K2:K4),2))
6. ใช้ Prompt Framework ให้ AI ตรวจสูตร โดยแนบโครงสร้างคอลัมน์และผลที่คุณคำนวณมือ
7. ทดสอบ: ลบ Quantity 1 แถว, ใส่ข้อความใน Unit_Price, ใส่ยอดติดลบ (คืนสินค้า) แล้วบันทึกว่าผลเปลี่ยนอย่างไร

**เฉลย (Answer Key)**

1. Amount: O001 = 12×150 = 1,800; O002 = 8×220 = 1,760; O003 = 10×150 = 1,500
2. ยอดรายวัน: 2026-10-01 = 1,800; 2026-10-02 = 1,760; 2026-10-03 = 1,500
3. ยอดรวม =SUM(G2:G100) = 5,060
4. ค่าเฉลี่ยรายวัน =ROUND(AVERAGE(K2:K4),2) = 1,686.67
5. ตรวจซ้ำ: SUM(K2:K4) = 5,060 ต้องเท่ากับยอดรวมทั้งหมด
6. แถวทดสอบ Quantity ว่าง → Amount เป็น "" ไม่ถูกรวม; Unit_Price เป็นข้อความ → E2*F2 ได้ #VALUE! ซึ่งทำให้ SUM ทั้งคอลัมน์เป็น #VALUE! ต้องแก้ข้อมูลหรือใช้ IF(NOT(ISNUMBER(F2)),"ตรวจข้อมูล",E2*F2)

**เกณฑ์ตรวจ**

- [ ] สูตรถูกต้องอย่างน้อย 80% ของรายการคำนวณ (Amount, ยอดรายวัน, ยอดรวม, ค่าเฉลี่ย, ตรวจซ้ำ)
- [ ] อธิบายได้ว่าทำไม AVERAGE ไม่นับวันว่าง และค่าเฉลี่ยนี้หมายถึงต่อวันที่มีการขาย
- [ ] ทดสอบกรณีผิดปกติได้อย่างน้อย 2 กรณี (ค่าว่าง, ข้อความ, ยอดติดลบ) และบอกผลที่เกิดขึ้น
- [ ] ใช้ $ ล็อกช่วงใน SUMIF ถูกต้องเมื่อลากสูตร
- [ ] ยอดรวมรายวันรวมกันเท่ากับยอดรวมทั้งหมด

### Workshop 2: ประเมินสถานะผ่าน/ไม่ผ่านจากสองเงื่อนไข

- เวลา: 30 นาที

- ข้อมูล: ชีต Raw_Data: A Farm_ID (F001–F004), B Score (คะแนน 0–100 ตัวเลข), C Check ("ผ่าน"/"ไม่ผ่าน"/ว่าง) — ข้อมูลสมมติ 8 แถว รวมแถวคะแนน 50, 51, ว่าง และ "ขาดสอบ"

- เป้าหมาย: สร้างคอลัมน์สถานะจากเงื่อนไข 2 ข้อตามรูปแบบ B02 พร้อมจัดการค่าว่างและข้อมูลผิดชนิด และสรุปจำนวนผ่าน/ไม่ผ่าน

**ขั้นตอน**

1. เขียนกฎเป็นภาษาคนก่อน: "ถ้าคะแนนมากกว่า 50 และผลตรวจเท่ากับ ผ่าน ให้ 100 นอกนั้น 0"
2. D2: สูตรต้นฉบับ =IF(AND(B2>50,C2="ผ่าน"),100,0) แล้วลากลง
3. E2: สูตรป้องกัน =IF(B2="","",IF(NOT(ISNUMBER(B2)),"ตรวจข้อมูล",IF(AND(B2>50,C2="ผ่าน"),100,0)))
4. F2: สถานะข้อความ =IF(E2=100,"ผ่าน",IF(E2=0,"ไม่ผ่าน",E2))
5. สรุป: =COUNTIF(F2:F100,"ผ่าน"), =COUNTIF(F2:F100,"ไม่ผ่าน"), =COUNTIF(F2:F100,"ตรวจข้อมูล")
6. ให้ AI อธิบายผลกรณี B2=50, B2=51 และ C2 ว่าง (Prompt B02) แล้วเทียบกับผลในชีต
7. บันทึกว่าแถว "ขาดสอบ" ได้ผลอะไรในสูตรต้นฉบับเทียบกับสูตรป้องกัน

**เฉลย (Answer Key)**

1. B2=51, C2=ผ่าน → 100 (ผ่าน)
2. B2=50, C2=ผ่าน → 0 เพราะ 50 ไม่มากกว่า 50 (ถ้ากฎคือ "ตั้งแต่ 50" ต้องเปลี่ยนเป็น >=)
3. C2 ว่าง → 0 (ไม่ผ่าน)
4. B2 ว่าง → สูตรต้นฉบับได้ 0, สูตรป้องกันได้ "" (ยังไม่ประเมิน)
5. B2="ขาดสอบ", C2=ผ่าน → สูตรต้นฉบับได้ 100 (ผิด! เพราะข้อความถือว่ามากกว่าตัวเลข) สูตรป้องกันได้ "ตรวจข้อมูล"
6. จำนวนสรุปต้องรวมกันเท่ากับจำนวนแถวที่มีคะแนน

**เกณฑ์ตรวจ**

- [ ] สูตรถูกต้องอย่างน้อย 80% ของแถวทดสอบ
- [ ] อธิบายความต่างของ > กับ >= ด้วยกรณี 50/51 ได้
- [ ] ชี้ได้ว่าข้อความในคอลัมน์คะแนนทำให้สูตรต้นฉบับผิด และแก้ด้วย ISNUMBER
- [ ] สรุปจำนวนผ่าน/ไม่ผ่าน/ตรวจข้อมูลครบและรวมกันได้จำนวนแถว
- [ ] ทดสอบกรณีผิดปกติ (ว่าง, ข้อความ, ช่องว่างท้ายคำว่า "ผ่าน ") ได้

### Workshop 3: แยกรหัส Lot และรักษาเลขศูนย์นำหน้า

- เวลา: 40 นาที

- ข้อมูล: ชีต Raw_Data: B Lot_Code (ข้อความ) ตัวอย่าง BR-2026-001, BR-2026-015, BR-2025-120, BR2026001 (ผิด), "BR-2026-007 " (มีช่องว่างท้าย) — ผลลัพธ์ไว้ที่คอลัมน์ H:L

- เป้าหมาย: แยกรหัส Lot รูปแบบ BR-2026-001 เป็น Prefix, Year (ตัวเลข), Running No. (ข้อความ 3 หลัก) ทั้งแบบ TEXTSPLIT และสูตรรุ่นเก่า และ Flag รหัสผิดรูปแบบ

**ขั้นตอน**

1. ตรวจรูปแบบก่อน: L2 =IF(LEN(TRIM(B2))-LEN(SUBSTITUTE(TRIM(B2),"-",""))=2,"รูปแบบถูก","รูปแบบผิด")
2. Microsoft 365/2024: H2 =TEXTSPLIT(TRIM(B2),"-") (Spill 3 คอลัมน์ H:J) — เว้นคอลัมน์ให้ว่าง
3. ทุกเวอร์ชัน (ถ้าไม่ใช้ TEXTSPLIT): H2 =LEFT(TRIM(B2),FIND("-",TRIM(B2))-1)
4. I2 (Year เป็นตัวเลข): =VALUE(MID(TRIM(B2),FIND("-",TRIM(B2))+1,FIND("-",TRIM(B2),FIND("-",TRIM(B2))+1)-FIND("-",TRIM(B2))-1))
5. J2 (Running No. เก็บศูนย์): =RIGHT(TRIM(B2),LEN(TRIM(B2))-FIND("-",TRIM(B2),FIND("-",TRIM(B2))+1))
6. K2 ตรวจย้อนกลับ: =EXACT(TRIM(B2),H2&"-"&I2&"-"&J2)
7. ใช้ Prompt B04 ให้ AI เปรียบเทียบสองแนวทาง แล้วทดสอบกับรหัสผิดรูปแบบในชีตจริง

**เฉลย (Answer Key)**

1. BR-2026-001 → BR | 2026 | 001 (J เป็นข้อความ ชิดซ้าย, I เป็นตัวเลข)
2. BR-2025-120 → BR | 2025 | 120
3. "BR-2026-007 " → TRIM แล้วได้ BR | 2026 | 007
4. BR2026001 → L = "รูปแบบผิด", สูตรแยกได้ #VALUE! (TEXTSPLIT คืน BR2026001 ทั้งก้อนในคอลัมน์แรก)
5. K2 = TRUE ทุกแถวที่รูปแบบถูก
6. ตรวจศูนย์นำหน้า =LEN(J2)=3 และ =ISTEXT(J2) ต้อง TRUE

**เกณฑ์ตรวจ**

- [ ] สูตรแยกถูกต้องอย่างน้อย 80% ของรหัสตัวอย่าง
- [ ] Running No. ยังเป็น 001/007 (ไม่กลายเป็น 1/7) และอธิบายได้ว่าทำไม
- [ ] อธิบายข้อจำกัดเวอร์ชันของ TEXTSPLIT (2024/365/Web) และ #SPILL!
- [ ] Flag รหัสผิดรูปแบบได้ และไม่กลบด้วย IFERROR โดยไม่บอกผู้ใช้
- [ ] ทดสอบกรณีช่องว่างเกินและขีดหาย

### Workshop 4: ค้นหาราคาจาก Master Data

- เวลา: 40 นาที

- ข้อมูล: ชีต Master_Data: A Product_ID, B Product_Name, C Price (P001 Product A 150, P002 Product B 220) · ชีต Product_Master: A Product_ID, B Product_Name, C Category (ตามต้นฉบับ) · ชีต Sales_Data: C Product_ID (เพิ่มแถวทดสอบ P009 และ "P001 ")

- เป้าหมาย: ดึงราคาและชื่อสินค้าจาก Master_Data/Product_Master มาใส่ Sales_Data ด้วย XLOOKUP และสูตรรุ่นเก่า พร้อมตรวจรหัสไม่พบและรหัสซ้ำ

**ขั้นตอน**

1. ตรวจ Master ก่อน: D2 ใน Master_Data =COUNTIF($A$2:$A$200,A2) ต้องเป็น 1 ทุกแถว
2. Sales_Data H2 (365/2021+): =XLOOKUP(C2,Master_Data!$A$2:$A$200,Master_Data!$C$2:$C$200,"ไม่พบสินค้า")
3. Sales_Data I2 (2013+): =IFNA(VLOOKUP(TRIM(C2),Master_Data!$A$2:$C$200,3,FALSE),"ไม่พบสินค้า")
4. Sales_Data J2 Category: =IFERROR(INDEX(Product_Master!$C$2:$C$100,MATCH(C2,Product_Master!$A$2:$A$100,0)),"ไม่พบ")
5. เทียบราคาที่ค้นได้กับ Unit_Price เดิม: K2 =IF(ISNUMBER(H2),H2=F2,"ตรวจ")
6. นับไม่พบ: =COUNTIF(H2:H100,"ไม่พบสินค้า")
7. ใช้ Prompt B03 และ B07 ให้ AI อธิบายและแนะนำวิธีตรวจรหัสซ้ำ

**เฉลย (Answer Key)**

1. O001 (P001) → 150, O002 (P002) → 220, O003 (P001) → 150 ตรงกับ Unit_Price ทุกแถว (K = TRUE)
2. P009 → "ไม่พบสินค้า" ทุกสูตร
3. "P001 " (ช่องว่างท้าย) → XLOOKUP ได้ "ไม่พบสินค้า" แต่สูตร TRIM ใน I2 ได้ 150 แสดงให้เห็นว่าต้องทำความสะอาดคีย์
4. Category: P001 → Feed, P002 → Equipment
5. COUNTIF ใน Master ทุกแถวได้ 1 = ไม่มีรหัสซ้ำ

**เกณฑ์ตรวจ**

- [ ] สูตรค้นหาถูกต้องอย่างน้อย 80% ของแถวทดสอบ
- [ ] ใช้ $ ล็อกช่วง Master และใส่ FALSE/0 สำหรับ Exact Match
- [ ] อธิบายสาเหตุของ "ไม่พบ" ได้อย่างน้อย 2 แบบ (ไม่มีจริง, ช่องว่าง, ชนิดข้อมูล)
- [ ] มีสูตรตรวจรหัสซ้ำ และเสนอทางเลือกสำหรับผู้ใช้ Excel รุ่นเก่า
- [ ] ไม่ใช้ IFERROR คืน 0 ที่อาจถูกรวมยอดผิด

### Workshop 5: คำนวณอายุไก่จาก Placement Date และ Assessment Date

- เวลา: 35 นาที

- ข้อมูล: ชีต Raw_Data: A Farm_ID (F001–F004), B Lot_Code, C Placement_Date, D Assessment_Date — ตัวอย่าง F001 2026-09-17 → 2026-10-01 และ 2026-10-08, F002 2026-09-17 → 2026-10-01, F003 วันประเมินก่อนวันรับลูกไก่ 1 แถว, F004 วันที่เป็นข้อความ "2026-10-01" 1 แถว · ชีต Farm_Performance: Age_Days สำหรับเทียบ

- เป้าหมาย: คำนวณอายุไก่แบบ Day 0 และ Day 1 ตรวจวันที่ที่เป็นข้อความหรือย้อนกลับ และเทียบกับ Age_Days ใน Farm_Performance (ข้อมูลสมมติ)

**ขั้นตอน**

1. ยืนยันนิยามกับผู้รับผิดชอบข้อมูล: วันรับลูกไก่ = Day 0 หรือ Day 1 แล้วจดใน Instructions
2. ตรวจชนิดวันที่: G2 =AND(ISNUMBER(C2),ISNUMBER(D2))
3. E2 (Day 0): =IF(OR(C2="",D2=""),"",IF(D2<C2,"ตรวจวันที่",D2-C2)) จัดรูปแบบ General
4. F2 (Day 1): =IF(ISNUMBER(E2),E2+1,E2)
5. แปลงวันที่ข้อความ (ถ้ามี) ด้วย =DATE(LEFT(D2,4),MID(D2,6,2),RIGHT(D2,2)) ในคอลัมน์ช่วย แล้วตรวจใหม่
6. เทียบกับ Farm_Performance: อายุ Day 0 ของ F001 ณ 2026-10-01 ต้องเท่ากับ Age_Days = 14
7. ใช้ Prompt B05 ให้ AI อธิบาย Day 0/Day 1 และตรวจกรณี B2 ก่อน A2 แล้วเทียบผล

**เฉลย (Answer Key)**

1. F001 2026-09-17 → 2026-10-01: Day 0 = 14, Day 1 = 15 (Day 0 ตรงกับ Age_Days 14)
2. F001 2026-09-17 → 2026-10-08: Day 0 = 21, Day 1 = 22 (ตรงกับ Age_Days 21)
3. F003 วันประเมินก่อนวันรับลูกไก่ → "ตรวจวันที่"
4. F004 วันที่เป็นข้อความ → G2 = FALSE; ลบวันที่ตรง ๆ อาจได้ #VALUE! หรือผลที่ขึ้นกับการตั้งค่าเครื่อง จึงต้องแปลงด้วย DATE(LEFT,MID,RIGHT) ก่อน
5. สรุป: ข้อมูลตัวอย่างสอดคล้องกับนิยาม Day 0 (วันรับลูกไก่ = อายุ 0 วัน)

**เกณฑ์ตรวจ**

- [ ] สูตรอายุถูกต้องอย่างน้อย 80% ของแถวทดสอบ
- [ ] อธิบายความต่าง Day 0/Day 1 และเลือกนิยามโดยอ้างอิงข้อมูล Age_Days ได้
- [ ] ตรวจวันที่ข้อความด้วย ISNUMBER และวันที่ย้อนกลับได้
- [ ] ไม่ใช้ TODAY() ในสูตรที่ต้องอ้างอิงวันที่ประเมินที่บันทึกไว้
- [ ] ระบุว่าข้อมูลเป็นข้อมูลสมมติ ไม่ใช่มาตรฐานสายพันธุ์
