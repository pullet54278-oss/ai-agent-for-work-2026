# สมุดสุขภาพครอบครัว (Family Health PWA) — เอกสารออกแบบ v0.1

> เอกสารนี้ไม่มีข้อมูลส่วนบุคคลจริง ข้อมูลจริง (ชื่อ เลขบัตรประชาชน ที่อยู่ ประวัติการรักษา)
> เก็บใน Firebase ของครอบครัวเท่านั้น และไม่ commit ลง repo นี้

## 1. เป้าหมาย

แทนสมุดสีชมพู แฟ้มใบรับรองแพทย์ ใบเสร็จ และใบประกาศผลการเรียน ด้วยแอปเดียวที่
พ่อและแม่ใช้ร่วมกันบนมือถือ Android ได้ โดยข้อมูลตรงกันทั้งสองเครื่อง

| ปัญหาเดิม | สิ่งที่แอปทำ |
|---|---|
| ลืมวันนัดวัคซีน (เช่น โน้ตกระดาษ "ไข้เลือดออกเข็ม 2") | ตารางนัด + แจ้งเตือนล่วงหน้า |
| ลงจุดกราฟการเจริญเติบโตเอง | คำนวณ z-score ตามเกณฑ์ WHO/กรมอนามัย แปลผลให้อัตโนมัติ |
| ภาวะพร่องเอนไซม์ G-6-PD อยู่ในสมุดเล่มเล็กที่ไม่ได้พกติดตัว | บัตรฉุกเฉิน + ตัวตรวจชื่อยา |
| ใบเสร็จคลินิกไม่บอกชื่อยา | บันทึกยา/ถ่ายรูปซองยาทุกครั้งที่ป่วย |
| ป่วยต่อเนื่อง (คอ → หลอดลม → ปอด) แต่ไม่เห็นภาพรวม | ไทม์ไลน์การเจ็บป่วย + เตือนป่วยซ้ำภายใน 14 วัน |
| ค่าใช้จ่ายกระจัดกระจาย | สรุปค่ารักษา/ค่าเรียน รายเทอม รายปี พร้อมสถานะการเบิก |

## 2. ผู้ใช้และสิทธิ์

- **ครอบครัว (family)** 1 กลุ่ม: สมาชิกที่ล็อกอินได้ = พ่อ, แม่ (สิทธิ์เท่ากัน อ่าน/เขียนได้ทั้งหมด)
- **โปรไฟล์ (person)** ที่ติดตาม: ลูก (หลัก), พ่อ, แม่ — เพิ่มลูกคนถัดไปได้
- ทุกบันทึกเก็บว่า "ใครบันทึก เมื่อไร" เพื่อให้พ่อแม่เห็นว่าอีกฝ่ายเพิ่มอะไร

## 3. สถาปัตยกรรม

```
 มือถือพ่อ (PWA)  ─┐                        ┌─ Firestore (ข้อมูล, offline cache)
                  ├── Firebase Auth ────────┼─ Cloud Storage (รูปเอกสาร ใบเสร็จ ซองยา)
 มือถือแม่ (PWA)  ─┘   (Google Sign-In)       ├─ Cloud Functions (ตั้งเวลาส่งแจ้งเตือนทุกเช้า)
                                            └─ FCM (Web Push → Android)
```

| ส่วน | เลือกใช้ | เหตุผล |
|---|---|---|
| Frontend | Vite + React + TypeScript, `vite-plugin-pwa` | ติดตั้งลงหน้าจอ Android ได้ ใช้งานออฟไลน์ |
| Auth | Firebase Auth (Google Sign-In) | ทั้งคู่มีบัญชี Google บน Android อยู่แล้ว |
| ฐานข้อมูล | Cloud Firestore + offline persistence | sync อัตโนมัติ ใช้ได้แม้สัญญาณใน รพ. ไม่ดี |
| ไฟล์ | Cloud Storage | รูปใบเสร็จ ใบรับรองแพทย์ ใบประกาศ สลิป |
| แจ้งเตือน | Cloud Functions (scheduled, 07:00 น.) + FCM | PWA ตั้งเวลาแจ้งเตือนเองไม่ได้ ต้องมีฝั่งเซิร์ฟเวอร์ส่ง |
| Hosting | Firebase Hosting | อยู่ในโปรเจกต์เดียวกัน |
| ค่าใช้จ่าย | แผน Blaze (จ่ายตามใช้) | ปริมาณใช้ของครอบครัวเดียวอยู่ในโควตาฟรี ≈ 0 บาท/เดือน แต่ต้องผูกบัตรเพื่อใช้ Cloud Functions |

**ความปลอดภัย**
- Firestore Security Rules: อ่าน/เขียนได้เฉพาะ uid ที่อยู่ใน `families/{id}.members`
- ล็อกแอปด้วยลายนิ้วมือ/PIN ของเครื่อง (WebAuthn) เมื่อเปิดแอปหลังพักเกิน 5 นาที
- เลขบัตรประชาชนแสดงแบบปิดบัง `1-xxxx-xxxxx-22-9` กดค้างเพื่อดูเต็ม
- ส่งออกข้อมูลทั้งหมดเป็นไฟล์ JSON + รูป (สำรอง/ย้ายระบบ) ได้ทุกเมื่อ

## 4. โครงหน้าจอ

แถบล่าง 5 แท็บ + ปุ่ม `+` ลอย (บันทึกด่วน) + ปุ่มบัตรฉุกเฉินที่หัวทุกหน้า

```
┌───────────────────────────────┐
│ [รูปลูก] น้อง…  4 ปี 5 เดือน ▾  [🆘 G6PD] │  ← สลับโปรไฟล์ / บัตรฉุกเฉิน
├───────────────────────────────┤
│              เนื้อหา             │
│                          ( + ) │
├─────┬─────┬─────┬─────┬─────┤
│ หน้าหลัก│สุขภาพ│การเรียน│ค่าใช้จ่าย│ เพิ่มเติม │
└─────┴─────┴─────┴─────┴─────┘
```

### 4.1 หน้าหลัก
- **นัดถัดไป** (วัคซีน/หมอ/ค่าเทอม) เรียงตามวัน พร้อมนับถอยหลัง
- **สถานะการเจริญเติบโตล่าสุด** (น้ำหนัก/ส่วนสูง/รูปร่าง + สี)
- **การ์ดเตือน** เช่น "ป่วย 2 ครั้งใน 14 วัน", "ยังไม่ได้ชั่งน้ำหนักเกิน 3 เดือน"
- ปุ่มลัด: บันทึกป่วย · ชั่งน้ำหนัก · ตรวจชื่อยา · แนบใบเสร็จ

### 4.2 สุขภาพ (แท็บย่อย)
1. **การเจริญเติบโต** — กราฟ 3 แบบตามสมุดสีชมพู (น้ำหนัก/อายุ, ส่วนสูง/อายุ, น้ำหนัก/ส่วนสูง) + รอบศีรษะ
   แบ่งระดับ 5 ระดับ (น้ำหนัก, ส่วนสูง) และ 6 ระดับ (รูปร่าง) ด้วยเส้น −2, −1.5, median, +1.5/+1, +2, +3 SD
2. **วัคซีน** — ตาราง EPI ของประเทศไทย (แรกเกิด–12 ปี) + วัคซีนเสริม; สถานะ ✅ ได้รับแล้ว / ⏰ ถึงกำหนด / ⚠️ เลยกำหนด;
   เก็บวันที่ เลข Lot สถานที่ รูปสติกเกอร์ และ "เข็มที่ x จาก y"
3. **การเจ็บป่วย** — ไทม์ไลน์; แต่ละครั้งมี วันที่ สถานที่ แพทย์ การวินิจฉัย อาการ ยาที่ได้ (ตรวจ G-6-PD อัตโนมัติ)
   คำแนะนำแพทย์ วันพัก นอน รพ. (AN, วันเข้า–ออก) เอกสารแนบ ค่าใช้จ่าย
4. **พัฒนาการ (DSPM)** — รายการทักษะตามช่วงอายุ 5 ด้าน ติ๊ก ผ่าน/ไม่ผ่าน + คำแนะนำส่งเสริม
5. **ตรวจคัดกรอง** — TSH/PKU, การได้ยิน, สายตา, ฮีโมโกลบิน/ฮีมาโตคริต, ฟัน (จำนวนซี่/ฟันผุ)
6. **ข้อมูลแรกเกิด** — การคลอด อายุครรภ์ น้ำหนัก ความยาว รอบศีรษะ Apgar
7. **G-6-PD** — ข้อปฏิบัติ 5 ข้อ, รายการ 🔴 ห้ามใช้ / 🟡 ใช้ด้วยความระมัดระวัง, อาหาร/สารเคมี, ตัวตรวจชื่อยา

### 4.3 การเรียน
- ปีการศึกษา → เทอม → โปรแกรม (เช่น EIS, IEP, จินตคณิต) → วิชา/ทักษะ: คะแนนได้/คะแนนเต็ม, เกรด, ความเห็นครู
- เกณฑ์เกรดกำหนดได้ต่อโปรแกรม (เพราะแต่ละใบประกาศใช้เกณฑ์ต่างกัน)
- กราฟเทียบรายเทอม + แนบรูปใบประกาศ
- ข้อมูลโรงเรียน ชั้น/ห้อง/เลขที่ รหัสนักเรียน เบอร์โทรโรงเรียน

### 4.4 ค่าใช้จ่าย
- หมวด: ค่ารักษา · ค่าเรียน (ค่าธรรมเนียม/อาหาร/โปรแกรม/เรียนพิเศษ/ชุด) · อื่น ๆ
- ประเภท: ครั้งเดียว · รายเทอม · **รายเดือน (มีเดือนเริ่ม–จบ)** · รายปี
- ป้ายสถานะ: 🟢 มีหลักฐาน · 🟡 ประมาณการ · ⚪ รอชำระ; ค่ารักษามีสถานะเบิก (ไม่เบิก/ยังไม่เบิก/ยื่นแล้ว/ได้รับเงิน)
- แนบใบเสร็จ + สลิปโอนคู่กัน; ปุ่ม "คัดลอกรายการจากเทอมก่อน"
- สรุปรายเทอม/รายปี แยกตามคนและหมวด

### 4.5 เพิ่มเติม
สมาชิกครอบครัว · สถานพยาบาลที่ใช้ประจำ (เบอร์โทร วันเวลาให้บริการ) · ตั้งค่าแจ้งเตือน · ส่งออก/สำรองข้อมูล · ล็อกแอป

### 4.6 บัตรฉุกเฉิน (เปิดได้จากทุกหน้า ใช้ได้แม้ออฟไลน์)
ชื่อ อายุ กรุ๊ปเลือด น้ำหนักล่าสุด · **⚠️ ภาวะพร่องเอนไซม์ G-6-PD** · ยาที่ห้ามใช้ (สรุป) · โรคประจำตัว/แพ้ยา ·
HN ของ รพ. · เบอร์โทรพ่อ/แม่ — ออกแบบให้ยื่นมือถือให้แพทย์/เภสัชกรดูได้ทันที

## 6. กฎการแจ้งเตือน (Cloud Function ทุกวัน 07:00 น. เวลาไทย)

| เหตุการณ์ | เตือนเมื่อ |
|---|---|
| นัดวัคซีน/นัดหมอ | 7 วัน, 1 วัน, เช้าวันนัด |
| วัคซีนตามตาราง EPI ที่ยังไม่บันทึก | เมื่อถึงอายุที่ควรได้รับ แล้วซ้ำทุก 7 วันถ้ายังไม่บันทึก |

| ป่วยซ้ำ | มีการเจ็บป่วย ≥ 2 ครั้งใน 14 วัน → แนะนำติดตามใกล้ชิด/พบแพทย์ |
| ยาที่บันทึกตรงรายการ G-6-PD | ทันทีที่บันทึก (ในแอป ไม่ต้องรอ 07:00) |

ส่งให้ทั้งพ่อและแม่; กด "รับทราบ/เลื่อนนัด" ได้จาก notification

## 7. ข้อมูลอ้างอิงที่ฝังในแอป

- ตารางวัคซีน EPI ประเทศไทย (กองโรคป้องกันด้วยวัคซีน)
- ตาราง LMS ของ WHO Child Growth Standards 2006 (0–5 ปี) และเกณฑ์อ้างอิงกรมอนามัย 2563 (5–19 ปี)
- รายการยา/อาหาร/สารเคมีจากสมุดประจำตัวผู้มีภาวะพร่องเอนไซม์ G-6-PD
  — ถ้าไม่พบชื่อยาในรายการ แอปแสดง "ไม่พบในรายการ ให้ปรึกษาแพทย์/เภสัชกร" (ไม่แสดงว่าปลอดภัย)
- รายการประเมินพัฒนาการ DSPM (กรมอนามัย)

## 8. การนำเข้าข้อมูลครั้งแรก

ข้อมูลจากเอกสารที่ส่งมา (สมุดสีชมพู สูติบัตร บัตร G-6-PD ใบรับรองแพทย์ ใบเสร็จ ใบประกาศ) จะเตรียมเป็นไฟล์
`seed.json` **นอก repo** แล้วนำเข้าผ่านหน้า "นำเข้าข้อมูล" ครั้งเดียว ยอดที่ไม่มีหลักฐานติดป้าย 🟡 ประมาณการ

## 9. แผนการพัฒนา

| ระยะ | เนื้อหา |
|---|---|

## 10. เรื่องที่ยังต้องยืนยัน

- เดือนเรียนพิเศษเทอม 2 (ตั้งไว้ พ.ย. 2569 – ก.พ. 2570)
- ไอคอนแอป: ได้รับรูปแล้ว ตัดเป็นสี่เหลี่ยมเต็มกรอบ (maskable) ขนาด 512/192/180/48 px ไว้ใน `icons/`
